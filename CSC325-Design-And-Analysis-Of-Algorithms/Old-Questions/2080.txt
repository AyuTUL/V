3. heapify:
-proicess of reaaraning array to maintain heap order property
time-O(log n)
space- O(log n) or O(1)

algorithm (max heapify):
-compare current node with left and right children
-find largest among the three
-if parrent isnt largest, swap with largest child
-recursivly call heapify on affected sub tree

MaxHeapify(A,i,n) {
	left=2*i*+1;
	right=2*i+2;
	largest=i;
	if(left<=n and A[left]>largest)
		largest=left;
	if(right<=n and A[right]>largest)
		largest=right;
	if(largest!=i) {
		swap(A[i],A[largest]);
		MaxHeapify(A,largest,n);
	}
}

5. insertion sort
-in palce and stable sorting algo that iterates through each element in unsorted array and
inserts them in correct position in sorted array
time-O(n^2)
space-O(1)

algorithm:
InsertionSort (A , n) {
	for(i = 1 ; i < n ; i++) {
		temp = A[i];
		j = i - 1;
		while(j >= 0 and A[j] > temp) {
			A[j+1] = A[j];
			j--;
		}
		A[j+1] = temp;
	}
}

6. min max
-finds min and max of unsorted array by dividing into 2 halves and returning max and min of each
half and comparing

algorithm:
MinMax (A, low, high) {
	if (low == high)
		max = min =A[low];
	else if (low == high-1) {
		if (A[low] < A[high]) {
			max = A[high];
			min = A[low];
		}
		else {
			max = A[low];
			min = A[high];
		}
	}
	else {
		mid = (low + high) / 2;
		{max , min} = MinMax (A, low, mid);
		{max1 , min1} = MinMax (A, mid+1, high);
		if (max1 > max)
			max = max1;
		if (min1 < min)
			min = min1;
	}
}

time-O(n)
sapce-O(logn)
