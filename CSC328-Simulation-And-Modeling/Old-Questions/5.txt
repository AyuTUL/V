methods of random number generation:
linear congruential:
	Xi+1 = (a.Xi + c ) mod m
where,
	X0: seed, starting point
	a: multiplier, controls randomness pattern
	c: increment, adds shift to sequence
	m: modulus, maximum range of values
	Xi: random integer, generated value

I: if c!=0, mixed congruential method
II: if c==0, multiplicative congruential method

arithmetic congruential:
	Xi+1 = (Xi-1 + Xi) mod m

mid square:
-take m digit seed number N0
-get square of same number N0^2
-square should be double digits of seed ie 2m else add zeroes at beginning
-take m digits from middle as next random number and use as seed
-repeat until same number chain occurs
