restoration in presence of noise only (spatial filtering):
-mean filter: 
	-reduce noise by replacing pizel value with value comupted from neighbourhood
	-sued to smooth images and reduce random noise

-arithmetic mean fileter:
	-replaces center pizel by average of all pixels in mask
	-smooths image, blurs edges
	-used for gaussian,uniform noise
	-formula: sum all pixels then divide by mxn

-geometric mean filter:
	-multiples all pixel values and takes nth root
	-less blurring that arithmetic mean
	-preserves details etter
	-used for multiplicative noise
	-formula: multiply all pixels then power 1/mn

-harmonic mean filter:
	-uses reciprocal of pixel values
	-used for sal nmoise, fails for peper noise
	-formula: mn / sum of 1/pixels

-contra harmonic mean filter:
	-extension of harmonic mean filter with parameter Q for controlling noise removal
	-used for salt and pepper, one at a timme
	-sensitive to zeroes
	-formula: sum all pixel power Q+1 / summ power Q


-order stastistics filter:
	-sort pixel values inside a negihbourhood and select/compte value from ordered list
	-non linear and good for impuklse noise

-median filter:
	-replaces center pixel with median value of sorted nieghbourhood
	-excellent for sal and pepper
	-presreves edges better than mean filter

-min max filter:
	-replaces pixel with min/max value in nieghbourrhood
	-removes salt / pepper noise
	-darkens/brightens image

-midpoint filter:
	-average of min and max valkues in neoghbouhood
	-used for gausiian,uniform noise

-alpha trimmed mean filter:
	-removes d/2 lowest and d/2 ihghset pixel values and calc mean of remiang pixel
	-combines mean and mdeian filter properties
	-used for mixed gaussian + impulse noise

huffman coding:
-lossless data compression technique to reduce data size by assingn varable length binary codes
to symbols
-more freuqnt symbols get shorter codes,less get longer

steps:
-count frequency of each symbo
-create leaf node for aech symbol
-build binary tree:
	-pick 2nodes with lowest frequencies
	-sum them into new node
-repeat till only root remains
-assign binary codes:
	-left edge:0
	-right edge:1
-codes obtained from root to leaf give huffman code
