Overflow Property

overflow: visible
This text is very long and will overflow outside the box because the overflow property is set to visible.
overflow: hidden
This text is very long and the extra content will be clipped and not visible outside the box.
overflow: scroll
This text is very long and scrollbars will appear even if they are not necessary.
overflow: auto
This text is very long and scrollbars will appear only if the content overflows.
overflow: auto
This text is too short for scrollbar to appear.
