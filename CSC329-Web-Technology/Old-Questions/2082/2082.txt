jQuery effects:

-hide/show HTML elements using hode() and show() methods

$(selector).show(speed,callback);
where,

	callback: function to be executed after hide() / show() completes

example:

		$("p").hide(1000);
	} 
);

-stop animations/effects before it is finished

example:

);

callback:
-optional parameter passed to jQuery effects 
-executed after method is completely fuinished, preveting errors that occur if lines of code run 
before effect is done

syntax:

example:

8. position property
-specifies type of positioning method used for element
-set positioin values then position useing tblr propoerties

static:
-deafult positionaing behaviour of element according to documeent flow
-ignores offset properties like tblr
-not affected by z index property

fixed:
-position element relative to browser window/viewport regardless of scrolling
-removed from normal docuemnt flow
-desont affect positioning of other elemetns, gets treated as invisble
-position is determined by offset properties tbrl in relation to viewport
-can overlap other elemnts on page, highset z index will be displayed on top
-used for sticky headers,sidebars,navigation menus

sticky:
-beahvse as relative within parent container until specified threshold is reached by scorlling
after which becomes fixed within viewport until scrolling reaches another specified point

relative:
-positioned relative to normal position, remain in normal flow of document
-other elemnts will not be adjusted to fit in gap left by relative elemnet
-can be layered using z index property
-when child is set to absolute with parent relative, child is positined relative to parent
instead of viewport, used for relative positionnng hierarchy

absolute:
-positioned relative to nearest positioned ancestor
-when child is set to absolute with parent relative, child is positined relative to parent
instead of viewport, used for relative positionnng hierarchy
-if no positioned ancestors, uses document body and moves along with page scrolling
-removee from normal flow and can overlap elemetns

float:
-position elemnt aloing left/right side of containing elemnt allowing other lements to flow
around it
-elemtne is taken out of normal document flow
-can be applied to block level elements

	left:elemnts float to left of containing element, others will flow around to its right
	right:elemnts float to right of containing element, others will flow around to its left
	none: deafult value,reamins in normal flow of document, other elements wont wrap around

<!DOCTYPE html>
<html>
<head>
    <title>Position Property</title>
    <style>
        #p1 {
            position: relative;
            left: 20px;
            color: blue;
        }
        #p2 {
            float: left;
            width: 40%;
            background: lightgrey;
        }
        #p3 {
            position: absolute;
            top: 100px;
            right: 50px;
            border: 1px solid red;
        }
    </style>
</head>
<body>
    <p id="p1">p1: Relative positioning (shifted 20px left).</p>
    <p id="p2">p2: Floated left; content wraps around me.</p>
    <p id="p3">p3: Absolute positioning (100px from top).</p>
</body>
</html>

<?php
if ($_SERVER['REQUEST_METHOD'] === "POST" && isset($_POST['submit'])) {
    $name = $_POST['nameField'];
    $password = $_POST['passwordField'];
    $country = $_POST['countryField'];
    $gender = $_POST['genderField'];
    $agree = $_POST['checkboxField'];

    $namePattern = "/^[A-Za-z0-9]{3,}$/";
    $passwordPattern = "/^(?=.*[A-Za-z])(?=.*\d)[A-Za-z\d]{6,}$/";

    $allowedCountries = ["Nepal", "Korea"];
    $allowedGenders = ["Male", "Female"];

    if (empty($name))
        echo "Name can't be empty.";
    elseif (!preg_match($namePattern, $name))
        echo "Name must be 3-20 chars, letters/numbers/underscore only.";
    elseif (empty($country))
        echo "Country can't be empty.";
    elseif (!in_array($country, $allowedCountries, true))
        echo "Invalid country selected.";
    elseif (empty($gender))
        echo "Gender can't be empty.";
    elseif (!in_array($gender, $allowedGenders, true))
        echo "Invalid gender selected.";
    elseif (empty($password))
        echo "Password can't be empty.";
    elseif (!preg_match($passwordPattern, $password))
        echo "Password must be at least 6 chars and include letters and numbers.";
    elseif (!$agree)
        echo "You must agree to the terms.";
    else
        echo "Validation successful.";
}
?>
