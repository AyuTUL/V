1. CSS:
-stylesheet language used to describe the presentation and formatting of a docuemtn written in
HTML or XML
-allows developers to control layot,design and overall visual appearance of web page by
seleecting elemnts and applying specific styles such as color,font and positioning

syntax:
selector { property-name:value;}
where,
	selector allows targeyting and styling specifc elements in HTML document

inline css:
-applying styles directly to individual HTML elemenets

internal css:
-defining styles within <style> tag in <head> section of HTML document

external css:
-definind styles in a separate CSS file and linking it to an HTML documnet using <link> tag
<link rel="stylesheet" href="style.css">

text-shadow:
-add shadow effect around text

syntax:
text-shadow: x-offset y-offset blur-amount spread-radius color inset;

box-shadow:
-add shadow effects around an element's frame
-can use multiple shadows using comma

syntax:
box-shadow: x-offset y-offset blur-amount spread-radius color inset;
where,
	blur-radius:blur
	spread-radius: +ve increases size of shadow, -ve decreases
	inset: changes shadow from outer to inner

<!DOCTYPE html>
<html>
<head>
	<title>CSS</title>
	<style>
		#div1 {
			text-shadow: 3px 2px green;
			box-shadow: 10px 10px blue;
		}
	</style>	
</head>
<body>
	<div id="div1">CSIT Exam</div>
</body>
</html>

2. jQuery:
-JS librarry that makes web pages qucker,easier, responsive and easy to handle rquest
-allows developers to plug routine JS features into web page so they can spend mroe time
focusing on complciated features unique to their site
-add animated effects,amke XML requests,manipulate DOM,client side validation

syntax:
$(selector).methodOrFunction();

jQuery selectors:
-specify set of elemetns based o ncertain atrributes like ID,class or type of tag to apply
jQuery methods/functions

syntax:
type of id - $("tag-name")
class - $(".class-name")
id - $("#id-name")
attribute - $("[href]")
attribute value - $("[href='index.html']")
pseudo state - $("a:first-of-type") , :first-child, :last-child, :first-of-type, :last-of-type
universal - $("*")

jQuery effects:
hide/show:
-hide/show HTML elements using hode() and show() methods

syntax:
$(selector).hide(speed,callback);
$(selector).show(speed,callback);
where,
	speed: slow,fast or in ms
	callback: function to be executed after hide() / show() completes

example:
$("button").click(
	function() {
		$("p").hide(1000);
	} 
);

fade:
-fade element in and out of visibliity
-fadeIn(), fadeOut(), fadeToggle(), fadeTo() mdethods

syntax:
$(selector).fadeIn(speed,callback);

example:
$("button").click(
	function() {
		$("p").fadeIn(1000);
	} 
);

slide:
-slide lements up and down
-slideDown(), slideUp(), slideToggle() methods

syntax:
$(selector).slideDown(speed,callback);

example:
$("button").click(
	function() {
		$("p").slideDown(1000);
	}
);

animate:
-create custom animations

syntax:
$(selector).animate({parameter},speed,callback);
where,
	parameter: css properties to be animated

example:
$("button").click(
	function() {
		$("p").animate(
			{
				left: 250px;
			}
		);
	}
);

stop:
-stop animations/effects before it is finished
-works for all jQuert fucntiosn

syntax:
$(selector).stop({parameter},stopAll,goToEnd);
where,
	stopAll: wheter animation queuees sohuld be cleared or not, default is false
	goToEnd: wheter to compelte current animation immediately or not, deafult is false

example:
$("button").click(
	function() {
		$("p").stop();
	}
);

callback:
-optional parameter passed to jQuery effects 
-executed after method is completely fuinished, preveting errors that occur if lines of code run 
before effect is done

syntax:
$(selector).function(speed,callback);

example:
$("button").click(
	function() {
		$("p").hide("slow",
				function() {
					alert("Paragraph has been hidden.");
				}
			);
	}
);

chaining:
-run multiple jQuery commands one after another on same element
-append next action to previous action

example:
$("button").click(
	function() {
		$("div")
		.css("color","red")
		.slideUp(2000)
		.slideDown(2000);
	}
);

3. XML eXtensible Markup Language
-arkup language that defines set of ruels for encoding documetns in both human and machine
readable format
-designed to store and transport data in a structured, self-descriptive, and 
platform-independent format
-used for Vector Markup Language (VML) for graphics, SMIL 2.0 for reusable multimedia content,
and configuration languages

<?xml version="1.0" encoding="UTF-8"?>
<library>
  <book id="B101">
    <title>Web Technologies</title>
    <price>550</price>
    <published_date>2024-04-10</published_date>
  </book>
</library>

<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:element name="library">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="book">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="title" type="xs:string"/>
              <xs:element name="price" type="xs:integer"/>
              <xs:element name="published_date" type="xs:date"/>
            </xs:sequence>
            <xs:attribute name="id" type="xs:string" use="required"/>
          </xs:complexType>
        </xs:element>
      </xs:sequence>
    </xs:complexType>
  </xs:element>
</xs:schema>
