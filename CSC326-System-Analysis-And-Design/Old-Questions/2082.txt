project management is controlled process of initiating, planning, executing, monitoring and
controlling and closing down a project

-project initiation phase:
	project manager is selected who will meet with project sponsor and key stakeholders to	
	determine objectives,historical info, who is needed in project
	
	output: project charter, preliminary scope statement, identification of all stakeholders,
	,division of proejct into phases

project planning phase:
	project manager determines team's roles,responsibilites and solidifes scope statement
	project plan is derived to address requirements like scope,budget,timeline
	project schedule is developed
	resources are allocated to project based on budget and schedule

	output: work breakdown structure WBS, WBS dictionary, communication, risk, test plan

project execution phase:
	longest, complex phase
	carrying out edtails of project charter, contructs delivarables and presents to
	stakeholders
	track project's progress and ensure milestones and delivarables stick to schedule
	project manger has to manage people,process,comms
	
	output: project completed on time & budget,team moral maintained, stakeholders
	satisfied with overall project progress

monitoring and control phase:
	monitoring is process of routinely gathering info on all aspects of project
	checking actual and likely progress against planned progress
	giving feedback about progess of project to donors,implementers,beneficiaries
	
	controling is data gathering, managemnt and analytical process to predit,understand and
	influcen the time and cost outcomes of poject
	making changes to plan if neccesary
	altering schedule
	escalating proobliesm if necessary
	taking action to avoid future problems

proejct clossure phase:
	process that performs controleld shiut down at end of project

9. installation
-process of moving from current IS to new
-all users give up reliance on current and rely on new

direct:
-changing from old ot new by turnign off old when new is turned on
-requires compelte installation of whoel sytem
-highrisk as there may be error that only shown in oeration

parallel:
-running old nad new at same time until management decides old can beturned off
-all work done in old is concurrently preformed by new
-outpus are compared to determine if new is performing as well as old
-errors in new dont cost oorganizmation much as they can be isolated
-expensive as all work is done twice, employ 2 staffs to opreate nad maintain
-confsiuing to users, not feasible forf large system due to redudant effort

pilot:
-single location installation
-chanign from current to new system only in one place linke branch office, department
-limits potential damage and cost by limiting effects to single site
-once management decides installation is succesfull in one lcoation, new deployed at rest
-simpler to user but diff to staff to support 2 versions
-extra program needed to synchronize current and new system

phased:
-staged
-parts of old and new are useed in coopreation till whole new system is installed
-by converting gradually, risk is spread out over time and place
-new and old must be able to coesxst and share data
-reuires c arfeul version control,repeaeted converstaion at each pahsae and long period of change
-frustraing to users
