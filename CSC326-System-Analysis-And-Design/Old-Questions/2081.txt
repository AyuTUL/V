normalization is database deisng process in which complex database tables are broken down
into simple separatetables

adv:
-identifies dependency between data fields
-minimzies data redundancy by storing data in only one place to save space
-faster sorting and indexing which improves perofrmance of database system
-simplifies maintenance due to smaller tables
-smaller tables without loss of information
-maintains data integrity by reducing data inconsistenices during updates

1NF:
-domain of each attribute contains only atomic avlues
-value of each attribute contains only single value from domain

-no partial dependecy, all non key attributes must depends on entire primary key, not just partly

-no transitive dependency, all non ke attrbutes must not depend on other non key attributes
